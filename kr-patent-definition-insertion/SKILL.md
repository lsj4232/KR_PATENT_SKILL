# 용어 정의 보완

청구항·본문에서 문맥만으로 의미가 불명확하거나 서로 다르게 쓰이는 용어를 골라 정의한다. 모든 명사를 정의하거나 동의어 개수를 채우지 않는다.

1. 용어의 사용 위치와 기존 정의, 발명자료의 근거를 확인한다. 표준 용어도 특별한 의미로 쓰는지 살핀다.
2. 지시하는 대상, 포함 정보·속성, 범위의 경계를 필요한 만큼 설명한다. 첫 실질 사용 부근의 본문 단락에 자연스럽게 삽입하고 중복 정의는 통합한다.
3. 동의어는 같은 대상을 실제로 가리킬 때만 병기한다. 근사해·정확해, 스키마·자유형식, 물리 구성·논리 구성의 차이를 문구로 덮지 않는다. 자료가 충돌하면 확인 사항으로 남긴다.
4. 예시는 개념 이해에 필요한 것만 넣는다. '이에 한정되지 않는다'가 근거 없는 확장이나 기술적 모순을 해결한다고 보지 않는다.
5. 원문 청구항, 도면, 다른 정의와 대조한다. 본문 보완 요청만으로 청구범위를 바꾸지 않는다. 청구항 변경도 요청되면 별도 변경으로 구분하여 관련 청구항 작성 스킬로 처리한다.

예시 문형: '본 명세서에서 [용어]는 [대상과 의미]를 지칭한다. [자료로 확인된 속성·범위]를 포함할 수 있다.' 문체는 기존 문서에 맞추며 확정형/가능형을 일률 강제하지 않는다.

열거된 항목은 차이가 해석에 중요할 때 각각 설명한다. 통상적인 데이터 소스 목록을 항목마다 장문으로 풀지 않는다.

출력은 삽입·통합 문단, 위치, 원자료 근거, 미확인 항목이다. 출원 후에는 최초 명세서·도면에 없는 의미 확장을 삽입하지 않는다. 정의 삽입만으로 권리범위 확대나 외부 해석 차단을 보증하지 않는다.
