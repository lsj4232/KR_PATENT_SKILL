# 한국 특허 명세서 본문 작성

청구항·발명자료·도면을 바탕으로 요청한 본문을 작성하거나 수정한다. 기존 청구항은 허용된 범위 밖에서 변경하지 않는다. 발명자 진술, 문헌의 사실, 작성자의 제안과 미확인 사항을 구별한다.

## 착수

- 정본·출원 전후 상태·수정 범위·제공 템플릿을 파악한다. 대화에 답이 있으면 다시 묻지 않는다.
- 청구항 구성별로 설명 근거와 도면 위치를 연결한다. 자료가 없으면 확인 필요로 표시하고 확보된 범위의 초안을 진행한다.
- G/H/혼합 분류로 필요한 참고자료를 고른다. 출원 카테고리와 문체를 분류만으로 강제하지 않는다.

## 본문 구성

기존 S 번호는 참조용이다. 아래 구성을 문서·요청에 맞게 적용한다.

| 구간 | 작성·검증 기준 |
|---|---|
| S1 명칭·기술분야 | 발명과 카테고리를 정확히 나타내고 불필요한 수식은 줄인다. 국·영문 명칭은 대응시킨다. |
| S2 배경기술 | 확인된 배경과 기술적 한계를 설명한다. 본 발명을 공지기술처럼 서술하지 않는다. 필요한 선행문헌 인용을 일률 금지하지 않는다. |
| S3 과제 | 자료로 확인되는 기술적 문제를 설명한다. 정해진 개수를 채우기 위해 과제를 만들지 않는다. |
| S4 해결수단 | 청구항의 구성·관계를 설명하고 누락 없이 대응을 확인한다. 대응 문단이 특정 위치에 없다는 사실과 명세서 전체의 뒷받침 부족을 구별한다. |
| S5 효과 | 구성 → 작동 원리 → 효과의 인과를 설명한다. 선택적 구성의 효과를 발명 전체의 필수 효과로 쓰지 않는다. 실측하지 않은 성능 수치를 만들지 않는다. |
| S11 도입 | 실시예의 대상과 전제를 소개한다. 무관한 모델·매체 목록이나 반복 보일러플레이트는 넣지 않는다. |
| S12 도면 설명 | 실제 도면 번호·종류·대상과 일치시킨다. 없는 도면은 설계안으로 구분한다. |
| S13 실시예 | 구성, 입력·처리·출력 또는 물리적 결합·작동을 이어 설명한다. 청구항 한정과 선택적 변형을 구분한다. |
| S14 마무리 | 필요한 구현·변형 설명만 남긴다. 효과나 매체 일반론을 의무적으로 반복하지 않는다. |
| S7 검토 | 청구항 근거, 용어·부호·도면, 인과관계, 미확인 사실, 내부 작성 메모의 잔존 여부를 점검한다. |

요약서·대표도 등은 요청한 산출물 범위에 포함될 때 작성한다. 분량·문단 수·접속어 빈도는 기술적 충실도의 대용 지표가 아니다. 기존의 600문장·25,000자·30페이지·보완 15~25문장 하한은 적용하지 않는다.

## 필요한 참고자료만 읽기

| 상황 | 참고자료 |
|---|---|
| AI·소프트웨어·제어의 구현 설명 | [SW/AI 보충](references/sw-ai-spec-supplement.md) |
| 기계·전기전자·화학의 구조·실시형태 설명 | [HW 보충](references/hw-mechanical-spec-rules.md) |
| 문체·표현 정리 또는 사무소 양식 적용 | [스타일 가이드](references/ko-patent-style-rules.md) |
| 도면이 없거나 도면 세트를 재설계 | [도면 세트 설계](references/drawing-set-design.md) |
| 저장매체항 또는 해외출원 대비가 요청됨 | [저장매체 검토](references/overseas-crm-support.md) |

## 보완과 결과

모호한 정의, 설명되지 않은 처리, 근거 있는 변형이 실제로 필요할 때만 각각 `kr-patent-definition-insertion`, `kr-patent-implementation-elaboration`, `kr-patent-embodiment-addition`을 사용한다. 세 스킬을 자동으로 연속 실행하지 않는다.

완성 초안과 구성별 근거표, 미확인 사항을 제공한다. 출원 후 수정은 최초 명세서·도면에서 근거를 확인하고 없으면 삽입하지 않는다. 전체 검토는 `kr-patent-consistency-check`, 요청된 DOCX 생성은 `kr-patent-docx-builder`로 이어간다. 필요한 법령·심사기준은 적용 시점의 공식 자료를 확인하며 작성 선호를 법적 요건으로 표현하지 않는다.
