# 한국 특허 본문 스타일 가이드

사용자가 다른 문체나 사무소 템플릿을 지정하면 그 지시를 따른다. 이 문서는 작성 선호이며 법령·심사기준을 대신하지 않는다.

| 부분 | 권장 접근 |
|---|---|
| 명칭 | 기술 대상을 식별할 수 있는 간결한 명칭. 과장된 평가어는 줄인다. |
| 기술분야 | 분야와 적용 대상을 짧게 설명한다. |
| 배경기술 | 확인된 배경 → 기존 접근 → 한계로 이어 쓴다. 필요한 문헌은 정확히 인용한다. |
| 과제 | 자료에 근거한 문제를 설명한다. 과제 수를 채우지 않는다. |
| 해결수단 | 청구항의 구성과 관계가 읽히도록 풀어 쓴다. |
| 효과 | 구조·동작이 어떤 이유로 효과를 내는지 연결한다. |
| 실시예 | 구성·동작·조건·결과를 이어 쓴다. 실제 도면과 연결한다. |
| 요약 | 핵심 기술 내용을 간결하게 제시하고 적용 서식의 요구를 확인한다. |

## 의미를 보존하는 편집

- '구성되는'과 '포함하는', '및'과 '또는'을 일괄 교체하면 의미가 달라질 수 있다. 실제 의도와 한정 관계를 확인한다.
- '종래'의 유무보다 공지 사실과 본 발명을 구분하는 내용이 중요하다.
- 용어·띄어쓰기·약어를 통일하되 인용문·제품명·청구항 원문은 허용 범위 내에서만 바꾼다.
- '상기'는 지시 대상을 명확히 할 때 쓴다. 도면부호가 있는 본문에서는 반복을 줄일 수 있다.
- 수식은 변수·단위·적용 조건을 설명한다. 실측값과 예시값을 구별한다.
- 긴 문장은 기술 관계가 보이도록 나누되 줄 수나 어절 수만으로 합격·불합격을 정하지 않는다.
- '한정되지 않는다'는 문장만으로 근거 없는 변형이나 모순이 해소되지는 않는다.

최종 산출물에서 내부 주석·설계 의도 메모·미확정 표지를 확인한다. 확인되지 않은 내용은 확정 원고와 구분하여 인계한다.
