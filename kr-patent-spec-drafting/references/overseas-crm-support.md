# 저장매체 관련 설명 검토

프로그램·저장매체항 또는 해외출원 대비를 요청받은 경우에만 사용한다. 모든 발명에 매체 보일러플레이트를 추가하지 않는다.

## 기술 내용

자료에서 명령어를 저장하는 매체, 실행 주체, 수행 동작을 확인하고 서로 연결해 설명한다. 시스템의 메모리와 별도로 배포되는 매체의 구분은 실제 설계와 개시 범위에 맞을 때 기술한다. 같은 내용을 해결수단과 맺음말에 두 번 복사할 필요는 없다.

비일시적(non-transitory)과 비휘발성(non-volatile)을 혼동하지 않는다. 매체의 예와 인터페이스·프로토콜의 예를 구별한다. 신호 전송과 저장매체를 같은 정의에 섞어 모순을 만들지 않는다.

## 확인 범위

- 프로그램/매체항의 동작이 본문에서 설명되는가?
- 다른 문단의 매체·신호 정의와 충돌하지 않는가?
- 해당 구현이 원자료에 있으며 출원 후라면 최초 명세서·도면에 근거가 있는가?
- 실제 기술적 효과와 근거를 설명했는가? 측정하지 않은 향상 수치를 만들지 않았는가?

미국 등 관할별 문언·적격성·보정 가능성은 그 시점의 공식 심사기준을 확인한다. 매체 문구 하나로 등록 가능성이나 해외출원 적합성을 보증하지 않는다. 국가별 출원 전략 메모는 기술 설명 본문과 구분한다.
