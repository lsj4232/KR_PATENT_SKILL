# 기계·전기전자·화학 구현 설명

물리적 구성·작동을 설명할 때 사용한다. G/H 분류로 청구항의 순서나 어미를 일률적으로 정하지 않는다.

## 실시형태와 자료

한 구조를 다른 각도로 보여주는 도면과, 서로 다른 해결 방식을 보여주는 복수 실시형태를 구별한다. 복수 실시형태는 공통 구성과 차이, 대응 도면을 분리해 독자가 관계를 알 수 있게 한다.

청구항·도면·발명자 설명을 중심으로 필요하면 CAD·사진·실험자료를 확인한다. 실제 자료가 없는 형상·재료·수치를 추측해서 채우지 않는다.

## 설명 기준

- 구성의 위치·방향·연결·접촉·연통·결합과 그에 따른 동작을 설명한다.
- 전기전자에서는 신호 경로·입출력·전원·제어 관계 중 발명에 필요한 부분을 밝힌다.
- 화학에서는 조성·조건·제조·측정 방법 중 관련 내용을 근거와 연결한다. 기계용 문형을 그대로 강제하지 않는다.
- 기본 실시형태와 선택적 구성·대체 구성을 구분한다. 확정형/가능형의 비율만으로 뒷받침을 판단하지 않는다.
- 도면 종류(사시도·단면도·회로도 등)를 정확히 적고 관찰 가능한 물리 관계를 대조한다.
- 동일 객체는 같은 부호를 사용한다. 다른 실시형태에서 같은 부호를 쓰는 경우 공통 부분인지 대응 부분인지 명시한다.

## 점검

위치·크기·형상의 관계가 성립하는지, 작동의 원인과 결과가 연결되는지, 대체 구성들이 양립하는지 확인한다. 도면의 수치가 있다는 이유만으로 삭제하지 말고 청구항·본문과의 의미와 근거를 검토한다.

배경기술은 사실과 출처에 맞게 작성한다. 특정 단어를 바꾸면 종래기술 자인 문제가 자동 해결된다고 보거나 선행문헌 인용 자체를 금지하지 않는다.

문서 서식은 제공 템플릿을 우선하고 DOCX 빌더의 실제 설정을 따른다. 사무소 선호를 공식 출원 요건으로 표시하지 않는다.
