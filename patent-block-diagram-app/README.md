# 특허 블록도 에디터 (Patent Block Diagram)

특허 도면용 블록도를 그리는 데스크톱 앱 (macOS / Windows).

## 특징

- **도형**: 사각형, 둥근 사각형, 마름모, 원기둥(DB), 구름(네트워크·외부 서버), 사용자(이용자 아이콘) — 사각형 계열은 우하단 검은색 오프셋 음영 (번짐 없는 특허 도면 스타일). 구름과 사용자는 특허 도면 관례대로 선만 그린다
- **화살표**: 직선 / 직각 꺾임, 화살표 선택 후 전환 가능. `화살표⁻`·`화살표⁺`로 선 굵기와 화살촉 크기를 함께 조절한다. 직각 화살표는 선택하면 가운데 구간에 주황 손잡이가 떠서 꺾임 위치를 끌어 옮길 수 있다 (PowerPoint의 꺾인 연결선과 동일). 끌어 옮긴 꺾임은 비율로 저장되어 박스를 옮겨도 비례해 따라온다
- **이미지**: 파일 열기 · 캔버스에 끌어다 놓기 · 클립보드 붙여넣기(화면 캡처). 도형과 똑같이 이동·크기조절·z순서·부호 태그·화살표 연결이 되고, 도면 파일 안에 그대로 실려 이식성이 유지된다
- **투명색 지정**: `투명색` 버튼을 누르고 이미지에서 없앨 색을 클릭하면 그 색과 같은 색(허용오차 안)이 전부 투명해진다. 잇달아 여러 색을 찍을 수 있고 `이미지 원본`으로 되돌린다
- **스마트 가이드**: 도형을 옮길 때 다른 도형의 가장자리·중심과 맞으면 붉은 파선이 뜨며 그 자리에 붙고, 좌우(위아래) 간격이 같아지는 순간에는 양끝 화살표로 등간격을 알려준다. 이미 있는 간격과 같아지는 자리도 잡아 주므로 3개 이상을 나란히 배치하기 쉽다. Alt를 누른 채 끌면 잠시 해제
- **도면부호 태그**: 물결(~) 지시선 + 숫자 (100, 110, … 자동 증가), 드래그로 위치 조절
- **텍스트**: 시스템 고딕 폰트 (macOS: Apple SD Gothic Neo, Windows: 맑은 고딕), 줄바꿈 지원
- **내보내기**: 고해상도(3×) PNG, 흰 배경
- **저장**: 자체 JSON 형식 저장/열기, ⌘/Ctrl+Z 실행 취소

## 설치 (Windows)

[Releases](../../releases)에서 `PatentBlockDiagram-Setup-*.exe`를 받아 실행.
(코드 서명이 없어 SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르면 됩니다.)

## 개발 실행

```bash
npm install
npm start
```

## 빌드

```bash
npm run dist:win   # Windows NSIS 설치본
npm run dist:mac   # macOS DMG
```

## 사용법

| 동작 | 방법 |
|---|---|
| 도형 생성 | 툴바 버튼 또는 빈 곳 더블클릭(사각형) |
| 텍스트 편집 | 도형 선택 후 툴바 입력창, 또는 도형 더블클릭 |
| 화살표 | `화살표 연결` → 시작 도형 → 끝 도형 클릭 |
| 화살표 크기 | 화살표 선택 → `화살표⁻` 또는 `화살표⁺`. 선과 화살촉이 함께 바뀌며 `기본`은 4pt로 되돌림 |
| 꺾임 위치 조절 | 직각 화살표 선택 → 가운데 구간의 주황 손잡이(또는 그 구간의 선)를 끌기. `경로 자동`으로 되돌림 |
| 정렬·등간격 맞추기 | 그냥 끌면 된다. 붉은 파선=정렬, 양끝 화살표=등간격. 붙는 게 거슬리면 Alt를 누른 채 끌거나 툴바 `스마트 가이드`를 끈다 |
| 이미지 넣기 | `이미지` 버튼, 또는 캔버스에 파일 끌어다 놓기, 또는 ⌘(Ctrl)+V로 캡처 붙여넣기 |
| 배경색 없애기 | `투명색` 누르고 이미지에서 없앨 색 클릭. 안 지워지면 옆 허용오차 숫자를 올린다(JPEG·안티에일리어싱). Escape로 모드 해제 |
| 채움 무늬 | 도형 선택 → `채움 바꾸기`. 흰칠 → 빗금(해치) → 점무늬 순으로 돈다. 표 머리행·합계행을 굵은 테두리 대신 면으로 강조할 때 쓰고, 글자가 겹쳐 읽기 어려우면 점무늬가 가장 연하다 |
| 부호 태그 | 도형 선택 → `부호 태그`, 숫자 더블클릭으로 수정 |
| 복사/붙여넣기 | 요소 선택 → ⌘(Ctrl)+C, ⌘(Ctrl)+V. 마지막에 복사한 쪽이 이긴다(앱에서 복사했으면 그 도형, 그 뒤에 화면 캡처를 떴으면 그 그림). ⌘(Ctrl)+Shift+V는 언제나 캡처 붙여넣기 |
| 삭제 / 실행취소 | Delete / ⌘(Ctrl)+Z |
