# 한국 특허 자료 진단

자료의 현재 상태와 다음에 필요한 작업을 짧게 제시한다. 진단만 요청하면 수정·후속 실행을 하지 않는다. 사용자가 진단 후 진행까지 요청했다면 그 권한을 유지한다.

## 확인할 것

1. 정본 파일과 버전, 요청한 산출물, 출원 전/후 상태를 파악한다. 날짜나 파일명만으로 최신본을 단정하지 않는다.
2. 청구항의 존재·인용관계, 본문 내용, 도면 원본, 용어·부호 대응, 검토 이력을 확인한다. DOCX는 본문뿐 아니라 표와 포함 도면도 살핀다.
3. 완료 / 보완 필요 / 미확인 / 해당 없음으로 기록하고 위치나 짧은 근거를 붙인다. 헤더 개수나 특정 문구의 빈도를 완성률로 환산하지 않는다.
4. `라 함은`, `한정되지 않는다`, `한편` 등의 유무만으로 정의·실시예의 완성 여부를 판정하지 않는다. 통상 의미나 문맥으로 충분히 설명된 용어도 인정한다.

## 다음 작업 선택

| 현재 부족한 것 | 추천 |
|---|---|
| 핵심 기술 내용 | Stage 1 / `kr-patent-inventor-meeting` |
| 독립항 초안 | Stage 2 / `kr-patent-claim1-drafting` |
| 종속항·추가 독립항 | Stage 2 / `kr-patent-dependent-claim-drafting` |
| 객체·부호 대응 | Stage 3 / `kr-patent-symbol-design` 또는 `kr-patent-drawing-mapping` |
| 본문 | Stage 4~5 / `kr-patent-spec-drafting` |
| 용어 의미 / 구현 설명 / 근거 있는 변형 | 해당하는 Stage 6 / 6.5 / 7만 |
| 완성 초안의 검토 | Stage 8 / `kr-patent-consistency-check` |
| 확인된 결함 수정 | Stage 9 / 해당 작성·편집 작업 |
| 최종 DOCX | Stage 10 / `kr-patent-docx-builder` |

방법항이나 선택적인 부호 설명표가 없다는 사실만으로 결함이라 하지 않는다. 도면이 필요한데 미제공인 경우에는 미확인으로 남기며, 다른 자료로 가능한 작업도 함께 제안한다.

## 출력

자료 현황표, 추천 작업과 이유, 작업을 막는 질문이 있으면 그 질문만 제시한다. 여러 단계 진행 요청에는 `kr-patent-full-workflow`를 사용한다. 진행률·예상 시간을 근거 없이 수치화하지 않는다.
