# 한국 특허 명세서 반복 정제

요청한 범위의 결함을 수정하고 재점검한다. 기본은 Priority A 해결, `strict` 요청 시 A+B, `perfect` 요청 시 합의된 문체 항목까지 포함한다. 문체 선호를 없애기 위한 무제한 반복은 하지 않는다.

## 기본값과 보호 범위

- 초기 점검 후 수정 회차는 최대 5회. 사용자가 지정한 범위·횟수가 있으면 따른다. 기본값을 쓰기 위해 별도 승인을 반복해서 받지 않는다.
- 청구항은 명시적으로 수정 요청된 경우 외에는 원문 텍스트를 보호한다. DOCX 전체 바이트는 재저장만으로 달라질 수 있으므로 청구항의 문단·런 텍스트를 비교하고 서식 변경은 따로 기록한다.
- 원본과 매 회차의 전체 산출물 사본을 보존한다. 출원 후에는 본문·도면의 추가·변경도 최초 출원 자료에 근거를 연결한다. 청구항 diff=0은 신규사항 없음의 증명이 아니다.
- `dry-run`은 수정 계획과 예상 영향만 출력한다.

## 반복

1. `kr-patent-consistency-check`로 초기 결함 목록을 만든다. 각 항목에 안정적인 ID, 위치, 근거, 우선순위, 해결 조건을 둔다. 도면 미제공 등 미검증 항목은 결함 0과 구별한다.
2. 목표 우선순위에 해당하고 자료로 해결 가능한 결함을 수정한다. 부호 충돌은 부호 대응을 먼저 확정하고 연관된 본문·도면을 함께 고친다. 설명 누락은 원자료에서 보충한다. 근거 없는 정의·변형을 생성하여 점수를 맞추지 않는다.
3. 청구항 보호 조건과 수정 구간·영향 구간을 검증한다. 출처 없는 내용이 추가되거나 원치 않은 변경이 있으면 그 회차 전체를 되돌리고 해당 자동 수정 경로를 중단한다. 청구항만 복원한 채 불일치 본문을 남기지 않는다.
4. 결함 ID별 해결 여부, 새 결함, 잔존 근거를 비교한다. 건수가 같더라도 다른 결함이 해결된 경우를 정체로 오인하지 않는다. 동일한 미해결 결함과 같은 수정 시도가 반복되거나 상태가 왕복하면 조기 종료한다.
5. 목표 결함 해소, 수정 가능한 항목 없음, 횟수 상한, 정체·퇴행 중 하나이면 종료한다. 성공 후 더 엄격한 모드를 자동으로 권하거나 실행하지 않는다.

## 출력

최종 파일과 변경 요약, 회차별 해결/잔존 결함 ID, 청구항 비교 결과, 미검증 범위, 종료 이유를 제공한다. 손상·퇴행 시에는 마지막 검증된 버전을 제공한다. 목표 항목이 없어도 '무결함', '출원 가능 보증'으로 표현하지 않는다. 모델별 고정 비용 추정치는 사용하지 않는다.
