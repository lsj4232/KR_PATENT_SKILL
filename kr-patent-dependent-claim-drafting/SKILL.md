# 종속항과 추가 독립항 작성

기준 독립항, 발명자료, 원하는 청구항 수·카테고리·수정 범위를 확인한다. 독립항이 아직 없으면 `kr-patent-claim1-drafting`으로 초안을 마련하거나 필요한 입력을 요청한다.

## 설계와 작성

1. 구성별 한정 후보를 원자료 위치와 연결한다. 방법항은 입력·처리·출력, 물건항은 구조·배치·결합·재료 등 실제 특징으로 분류한다.
2. 인용항, 추가되는 한정, 기술적 의미를 짧은 계획표로 정리하고 요청 범위 내 초안을 작성한다. 항별 승인은 사용자가 요청했거나 실질적 미정 선택이 있을 때만 받는다.
3. 부모항의 모든 한정을 유지하면서 추가 한정을 기재한다. 대체 실시예가 부모항과 양립하지 않으면 해당 부모에 종속시키지 않는다. 인용 누락·순환·선행 기재와 복수 인용 규정은 적용 관할 기준으로 확인한다.
4. 추가 독립항은 다른 보호 대상에 실제 의미가 있을 때만 둔다. 시스템·프로그램항을 모든 발명에 자동 추가하거나 후속 독립항을 무조건 더 넓게 만들지 않는다.
5. 최종 세트에서 중복 한정, 비어 있는 연결, 용어 불일치를 검토한다. 기초 독립항의 요청하지 않은 변경은 분리한다.

항 수·체인 깊이·어절 수·3줄 상한은 기본 요건이 아니다. 사용자의 예산·분량 지시와 기술적 필요에 맞춘다. 깊이를 채우기 위해 특징을 발명하거나 같은 특징을 여러 항으로 반복하지 않는다.

## 패턴 선택

- 요소 정의: '제N항에 있어서, 상기 [요소]는 [구체 속성]을 포함하는 …'
- 처리 구체화: '제N항에 있어서, 상기 [처리]는 [입력]에 [기준]을 적용하여 [결과]를 생성하는 …'
- 장치 한정: '제N항에 있어서, 상기 [부재]는 [배치·결합 관계]로 배치되는 …'

문형은 예시이며 한정의 의미가 우선한다. 소프트웨어 시스템은 메모리·프로세서와 실행 동작을 연결할 수 있고, 실제 물리 블록이 있는 장치는 그 실체를 기재한다. 다른 관할의 기능식 청구항 위험을 한국 문언의 일률 금지로 바꾸지 않는다.

## 결과

청구항 2~N, 인용관계표, 항별 추가 한정과 원자료 근거, 미확인 사항을 제공한다. 청구항 해설은 문언 밖에 둔다. 도면·본문 인계 시 기준 청구항 버전과 용어를 함께 전달한다.
