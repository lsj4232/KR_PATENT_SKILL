# 실시예 본문 집중 검토

【발명을 실시하기 위한 구체적인 내용】의 설명 충실도와 일관성을 검토한다. 전체 청구항·도면 대조는 `kr-patent-consistency-check`가 담당하므로 이미 나온 결함을 중복 보고하지 않는다.

## 기본 검토

- 구성요소와 동작 주체가 특정되고, 입력·처리·출력 또는 물리적 연결·작동이 이어지는가?
- 청구항의 한정과 관계가 본문에서 설명되는가? 선택적 변형이 필수 구성과 섞이지 않는가?
- 용어·수식·단위·부호의 의미가 문맥상 명확한가?
- 도면 설명이 실제 대상·순서·연결과 일치하는가? 자료가 없으면 미검증으로 남겼는가?
- 효과에 기술적 근거가 있으며, 실험하지 않은 결과나 존재하지 않는 구현을 단정하지 않는가?
- 내부 작성 메모, 불필요한 반복, 서로 충돌하는 보일러플레이트가 남아 있지 않은가?

## 선택적 ITER 10 문체 검사

사용자가 ITER 10 또는 기존 사무소 템플릿 준수를 요청할 때만 [ITER 10 참고 원문](references/iter10_drafting_prompt.md)을 읽는다. 이는 호환용 문체 템플릿이며 법적 요건이 아니다. 단락 수·접속어 빈도·'할 수 있다' 비율만으로 실체적 결함을 판정하거나 내용을 만들어 보충하지 않는다. 사용자의 범위와 자료의 사실이 우선한다.

## 결과

위치·원문·문제·근거·수정안을 제시한다. 실체적 문제와 선택된 문체 차이를 구분하고 미검증 범위를 명시한다. 검토만 요청하면 수정하지 않는다. 수정 요청이 있으면 허용된 부분을 고치고 청구항·도면과의 영향을 재점검한다.
